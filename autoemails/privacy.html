AutoEmails Privacy Policy

Last updated: November 3, 2026

AutoEmails is a personal tool used only by its developer on their own Gmail account. It is not distributed to or used by other people.

Data accessed

With the account owner's authorization, the app reads messages in the Gmail inbox (including sender, subject and body of the message and recent messages in its thread), adds or removes labels, and permanently deletes messages in Trash. It does not send email.

How data is used

Message content is sent to the OpenAI API solely to classify each message (irrelevant, needs reply, or keep). Requests are made with storage disabled. Data is used for no other purpose, and is not used for advertising or to train models.

Storage and sharing

The app keeps no database of email content. The Google authorization token is stored as an encrypted secret in the developer's private GitHub repository. Email data is not sold or shared with anyone other than OpenAI as described above.

Google API Services

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
